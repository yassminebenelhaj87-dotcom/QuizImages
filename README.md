## 1. Présentation

**Quiz en images** est une application Android développée en Kotlin avec une interface XML. Elle propose cinq questions illustrées sur les formes géométriques : triangle, carré, cercle, étoile et rectangle.

Pour chaque question, l'utilisateur choisit une réponse parmi trois propositions. L'application indique si la réponse est correcte, met à jour le score et la progression, puis affiche le résultat final.

## 2. Fonctionnalités

- Affichage de cinq questions avec une image associée.
- Trois choix de réponse pour chaque question.
- Affichage du score sur 5.
- Barre de progression indiquant le nombre de questions répondues.
- Message indiquant si la réponse est correcte ou incorrecte.
- Désactivation des choix après une réponse pour éviter de compter plusieurs fois la même question.
- Affichage du résultat final dans la même activité.
- Bouton **Rejouer** pour réinitialiser la partie.

## 3. Installation et exécution

1. Ouvrir Android Studio.
2. Choisir **Open** et sélectionner le dossier du projet.
3. Attendre la synchronisation Gradle.
4. Connecter un appareil Android ou démarrer un émulateur.
5. Cliquer sur **Run** pour compiler et lancer l'application.
